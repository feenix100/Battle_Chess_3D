# Rook game meshes

These four rigid mesh parts are assembled and animated by the Rust rook rig.

| File | Use |
| --- | --- |
| [rook.mesh](rook.mesh) | The brick parapet body |
| [brick.mesh](brick.mesh) | Reusable brick-shaped arms and legs |
| [hatch-left.mesh](hatch-left.mesh) | Left half of the opening upper battlement |
| [hatch-right.mesh](hatch-right.mesh) | Right half of the opening upper battlement |

The battlement opens for the drone launch. The limbs extend for movement and
fold away when the rook returns to its resting parapet shape.
