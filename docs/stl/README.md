# Exported piece STLs

Neutral-pose exports of the six in-game pieces. These are optional source-art
exports; the game embeds the `.mesh` files in [`art`](../../art).

| Piece | Export |
| --- | --- |
| Pawn | [pawn.stl](pawn.stl) |
| Knight | [warhorse.stl](warhorse.stl) |
| Bishop | [bishop.stl](bishop.stl) |
| Rook | [rook.stl](rook.stl) |
| Queen | [queen.stl](queen.stl) |
| King | [king.stl](king.stl) |

The generation scripts are in [`docs/blender`](../blender). The knight is adapted
from MZ4250's model under CC BY 4.0; see the [asset credits](../../art/README.md#knight-attribution).
