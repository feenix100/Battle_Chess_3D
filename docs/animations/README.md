# README images and capture GIFs

These images are used by the [main README](../../README.md). The GIFs are recorded
from the native game's animation systems and show the attack, target reaction,
and the capturing piece arriving on its new square. Each capture uses a close
side view that keeps the projectile's flight and impact visible. The knight's
framing includes its leap, and the king's camera moves closer after the bomb
descends. Each GIF loops at 560 x 315 pixels and 10 frames per second, with a
brief hold after the capture finishes.
